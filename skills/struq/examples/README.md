# Examples

Finished reference builds, one per group of businesses. Each is the skeleton of a real site the skill built and an
art director passed: `lib/site.ts` (every fact and line of copy), `app/page.tsx` (the scenes in order),
`app/world.tsx` or another signature, and one short file per scene, with screenshots and a README on how to adapt it.
Read the one nearest the brief, copy its skeleton and its patterns, then change the business: the facts, the object,
the scenes that do not fit. Never copy its copy, its name or its claims; every line on the new site comes from the new
brief. The kit itself is not here: install it with `blocks.mjs`, as for any site.

- [halden](halden/README.md): product brands and shops. A glass pendant maker in Bergen; one lamp in a 3D world
  carries the page from the first screen to an order close.
- [oostwerk](oostwerk/README.md): agencies and studios (neighbours: personal portfolios, creative freelancers). A web
  studio in Amsterdam; a canal at night fills the first screen, one lit door among dark windows, and the same street
  closes the page.
